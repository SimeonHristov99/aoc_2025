# Advent of Code 2025

Learning Go this year.

## Quick start

Pattern: `go run cmd/main.go -day <day_number;1..12> -part <part_number;1|2> -input <path_to_input_file>`

Example: `go run cmd/main.go -day 3 -part 2 -input internal/day03/input.txt`
